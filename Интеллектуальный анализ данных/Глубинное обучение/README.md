Здесь лежат тетрадки-выполненные домашние задания на курсах "Основы глубинного обучения" (5 семестр бакалавриата) и "Прикладные задачи анализа данных" (6 семестр бакалавриата):

1. **Полносвязные сети** - основные вещи при обучении нейросетей: предобработка данных, разделение выборки, написание слоёв, фукционал ошибки, метрики качества, и т. д.;
2. **Свёрточные сети** - классификация изображений и все сопутствующие задачи;
3. **Детекция объектов** - полное решение задачи детекции объектов (в том числе с помощью YOLO11);
4. **ИИ-агенты и API** - создание двух ИИ-агентов на LangChain и LangGraph (в последнем ещё задействовано подключение к API);
5. **Генерация** - генерация через WGAN, VarAE, диффузионные модели и нормализационные потоки;
6. **Временные ряды** - работа с временными рядами: анализ приведённых и предсказание последующих значений.
